# Smart Campus Issue Reporting App

A recreated portfolio version of the **Smart Campus Issue Reporting App**, originally developed as a Design Thinking project.

## Features
- Student home page
- Issue reporting form
- Issue categories and priorities
- Recently reported issues
- Issue status tracking
- Admin dashboard
- Dashboard statistics
- Admin status updates
- Responsive interface
- Browser LocalStorage for demo data

## Technologies
HTML5 · CSS3 · JavaScript · Browser LocalStorage

## Structure
```text
smart-campus-issue-reporting/
├── index.html
├── admin.html
├── style.css
├── script.js
├── admin.js
├── README.md
└── screenshots/
```

## Run
Open `index.html` in a browser. Submit an issue, then open `admin.html` to manage its status.

## Project Context
This is a recreated portfolio version because the original ZIP/source files were no longer available. It preserves the core project concept remembered from the original Smart Campus project rather than claiming to be the original source code.
